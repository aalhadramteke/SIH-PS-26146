# Dashboard visual assets

`emblem-of-india.svg` is the National Emblem of India, stored locally so the
offline dashboard does not depend on a remote CDN. Source: Wikimedia Commons,
[`File:Emblem_of_India.svg`](https://commons.wikimedia.org/wiki/File:Emblem_of_India.svg).

The dashboard labels itself as an SIH prototype using synthetic data. The
emblem is used for visual context only; this project is not an official
Government of India application or endorsement.
